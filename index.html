FrontierLitBench

A benchmark for frontier AI paper discovery. A request names a field, a year range and the venues that count; an agent returns five papers, ranked. The question is whether those five are the ones that actually moved the field.

The question

One request, five slots, three grades. Scoring uses only labels frozen before any agent ran.

Keyword search is not the hard part any more. The frontier moves weekly, and the papers that matter often sit a few citations away from the obvious ones. FrontierLitBench asks whether an agent can surface them, and whether it knows which of the five belongs first.

Every task fixes a track, a set of publication years and a venue whitelist. Answers are matched against a graded library by identity — DOI, arXiv, or a normalised title with its year — never by the agent's own description of what it found.

Recommendations outside the whitelist score nothing. A genuinely new eligible paper is adjudicated once, for every agent, before any score exists: the bar cannot be moved by the results it produces.

How the library was built

Four steps, all completed before the first run. The thresholds never move afterwards.

i

Candidate pool

Conference catalogues for 2024–2026, widened with sub-topic queries so recall is not decided by citation count.

ii

Verified identity

DOI, arXiv identifier and normalised title are cross-checked. Preprints merge into their accepted version.

iii

Impact grade

Q = 0.55 citations + 0.30 GitHub stars + 0.15 institution, percentile-normalised inside each track and year.

iv

Tiers S / A / B

Top fifth, next two fifths, last two fifths. Thresholds are locked and reused by later additions.

Venue whitelist, fixed per track

Library v1.1: 425 original gold papers and 332 adjudicated additions — 757 eligible (127 S, 351 A, 279 B), 31 rejected. Ideal DCG fixed at 14.7423.

Three numbers

Linear gains, 5 / 3 / 1 / 0, discounted by log₂ of the position. One primary, two to explain it.

nDCG@5 — primary

DCG = Σ g(pi) / log₂(i+1)

The same paper is worth more in the first slot than the fifth. That discount is the only reason ordering counts at all; the denominator is the best ordering the task allows.

WeightedHit@5

Σ g(pi) / 25 × 100

Quality of the set, blind to order. Read beside nDCG it separates finding good papers from arranging them well.

S-Tier Hit@5

Σ 1[g(pi) = 5]

How many of the five are top-tier. Reported with the number of top-tier papers available, because tasks differ in how much of the ceiling they offer.
